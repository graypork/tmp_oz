# Art Game Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the touch-friendly two-round spot-the-difference game, development-only polygon editor, and two-minute activity timer.

**Architecture:** Vite + React + TypeScript. Core geometry and timing helpers are framework-independent and tested with Node's built-in test runner. Normalized JSON data drives both game and editor.

**Tech Stack:** React 18, TypeScript, Vite, Node built-in tests.

**Spec:** `docs/superpowers/specs/2026-09-13-art-game-design.md`

## Global Constraints
- No backend or database.
- Only the left/adapted image accepts game input.
- O/X feedback renders on both images.
- Editor is development-only.
- Polygon coordinates and marker positions are normalized 0..1.
- Timer is exactly 120 seconds and starts only by explicit button press.
